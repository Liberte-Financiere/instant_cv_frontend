[2026-03-22] — Admin Task Board (Kanban interne)

What changed:
- Ajout du modèle Prisma AdminTask (status, priority, assignee)
- API CRUD admin-only: GET/POST /api/admin/tasks, PUT/DELETE /api/admin/tasks/[id]
- Page Kanban /admin/tasks avec 4 colonnes (A faire, En cours, En test, Terminé)
- Drag & drop HTML5 natif entre colonnes avec mise à jour optimiste
- Modal de création/édition avec titre, description, priorité, assigné, statut
- Layout admin avec guard serveur (redirect si non-admin)
- Badge de priorité coloré (basse/moyenne/haute)

Why:
- Permettre à l'équipe admin de gérer les tâches projet en interne sans dépendre de Trello

Files affected:
- prisma/schema.prisma — Nouveau modèle AdminTask
- app/api/admin/tasks/route.ts — GET (liste) + POST (création)
- app/api/admin/tasks/[id]/route.ts — PUT (update) + DELETE
- app/admin/layout.tsx — Guard serveur admin-only
- app/admin/tasks/page.tsx — Page Kanban complète

Breaking changes:
- None. Nouvelle feature isolée.

Notes for review:
- La migration a été faite via `prisma db push` (pas de fichier migration)
- Le drag & drop est natif HTML5, pas de dépendance externe
- Les emails admin sont en dur dans le guard (pattern existant)
