[2026-03-24] — feat(interview): Add audio/text format selection and dynamic per-minute billing

What changed:
- Added a Format Selector (Text vs Audio) on the Interview Setup page.
- Implemented a dynamic billing system for Audio interviews (1 credit per minute, billed proactively via the live SSE connection loop).
- Updated the database schema (`InterviewSession`) to store the chosen interview format.
- Locked the Interview UI to conform strictly to the chosen format (preventing users from bypassing audio billing by switching to text UI mid-session).

Why:
- To reflect the difference in AI real-time audio computation costs vs traditional text processing, making the platform's economics viable while offering an immersive voice experience.

Files affected:
- prisma/schema.prisma — Added format field to InterviewSession.
- lib/credits.ts — Adjusted AI_INTERVIEW base cost to 5 and added AI_INTERVIEW_AUDIO_MINUTE for 1 credit dynamic cost.
- app/dashboard/ai/interview/page.tsx — Built the Mode selection UI.
- app/api/ai/interview/route.ts — Session startup now registers the format and charges correctly based on selection.
- app/api/ai/interview/ws/[sessionId]/start/route.ts — Added a 60-second recurring billing interval to proxy WebSocket. Checks user balance real-time and disconnects if bankrupt.
- app/interview/[sessionId]/page.tsx — Replaced format Toggle buttons with fixed format Badges based on DB session settings.

Breaking changes:
- None. (New `format` defaults to "text", keeping legacy rows safe).

Notes for review:
