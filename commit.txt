2026-05-23 — Fix Input and Textarea Text Color Visibility Across Devices

What changed:
- Added explicit text-slate-900 color classes to custom Input, Textarea, and Select components.
- Added text-slate-900 to native textareas in CV forms (Experience, Projects, Divers).
- Added text-slate-900 and select styling overrides to Cover Letter editor forms and fields.
- Appended a global fallback style in globals.css to force slate-900 text on all inputs, textareas, and select components with appropriate placeholder styling.

Why:
- System dark mode settings on some devices (especially mobile Safari and Chrome) automatically styled typed text within inputs as white/light gray. Without an explicit text color configuration, white text on white/light backgrounds made typed content completely invisible.

Files affected:
- components/ui/Input.tsx — Added text-slate-900 to class lists
- components/ui/Textarea.tsx — Added text-slate-900 to class lists
- components/ui/Select.tsx — Added text-slate-900 to class lists
- components/editor/forms/ExperienceForm.tsx — Added text-slate-900 to native textarea class list
- components/editor/forms/ProjectsForm.tsx — Added text-slate-900 to native textarea class list
- components/editor/forms/DiversForm.tsx — Added text-slate-900 to native textarea class list
- app/cover-letter/editor/[id]/page.tsx — Added text-slate-900 to multiple textareas and select fields
- app/globals.css — Added global fallback color rules for inputs, textareas, and selects

Breaking changes:
- None
