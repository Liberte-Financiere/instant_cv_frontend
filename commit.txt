2026-03-29 — Masquage du nombre de questions pour les entretiens audio

What changed:
- Suppression du décompte dynamique du nombre de questions pour les entretiens audio côté API (réversion de la modif précédente).
- Masquage complet de la mention "X questions" sur le Dashboard principal et sur la page d'historique lorsque l'entretien est de type 'audio'.

Why:
- Demande explicite de l'utilisateur : il préfère ne pas afficher du tout le nombre de questions quand c'est un test vocal (puisque le format est plus fluide/conversationnel et ne se prête pas à un décompte strict).

Files affected:
- app/api/ai/interview/[sessionId]/route.ts — Retrait du `questionCount: Math.max(...)` lors du terminate de session.
- app/api/ai/interview/history/route.ts — Ajout du champ `format` dans le select Prisma renvoyé au dashboard.
- app/dashboard/ai/interview/page.tsx — Conditonnement de l'affichage `s.format !== 'audio' && <span>...</span>`.
- app/dashboard/ai/interview/history/page.tsx — Même condition de masquage pour la page complète.

Breaking changes:
- None

Notes for review:
- Le compteur de questions ne s'affichera désormais que pour les examens textuels.
