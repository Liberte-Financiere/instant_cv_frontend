[2026-06-21] — Implémentation Rognage Photo CV

What changed:
- Installed `react-easy-crop` dependency.
- Created `lib/cropImage.ts` utility to extract cropped images natively via HTML5 Canvas.
- Created `components/editor/CropModal.tsx` for a touch-friendly cropping interface with zoom.
- Refactored `components/editor/PhotoUpload.tsx` to intercept the file selection, display the `CropModal`, and upload the final cropped File.

Why:
- Users frequently uploaded rectangular or non-centered photos that looked bad on the final CV.
- Extracting the crop on the client side (Canvas) avoids expensive image processing on the Next.js server and saves Cloudinary storage by enforcing a max 400x400px resolution.

Files affected:
- package.json — Added react-easy-crop.
- lib/cropImage.ts — New canvas utility.
- components/editor/CropModal.tsx — New UI modal.
- components/editor/PhotoUpload.tsx — Integrated the modal into the upload flow.

Notes for review:
- The `cropShape="round"` property is used in the modal to guide the user visually, ensuring the face fits the CV's circular avatar design.
- The output resolution is currently capped at 400x400px in the canvas logic to optimize uploads.
