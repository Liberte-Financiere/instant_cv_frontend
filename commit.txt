[2026-03-28] — Refactor AI Interview to Native Chat Mode & Centralize Configs

What changed:
- Migrated the prompt structure for the mock interview from manual string concatenation ("RECRUTEUR:", "CANDIDAT:") to the native `startChat({ history })` Gemini API.
- Integrated `formatHistoryForGemini` to seamlessly convert Prisma database messages into `user` and `model` role blocks.
- Centralized `MAX_QUESTIONS` and Audio `model` config into `lib/config.ts`.
- Swapped simple prompts for `systemInstruction` where appropriately supported by `GoogleGenerativeAI`.

Why:
- To eliminate AI hallucinations regarding speaker roles during long interviews.
- Improved processing efficiency and token understanding by making the Prompt context explicit (Model vs User).
- Removed hardcoded constants scattered in TS logic to make the app maintainable and configurable from a single source of truth.

Files affected:
- lib/config.ts — Added `audioLive` model string and `interview.maxQuestions` setting.
- lib/interview.ts — Heavy refactor to adapt prompt builders into System Instructions, implemented `formatHistoryForGemini`, and replaced `generateContent` with `startChat` for answers.
- lib/interview-audio.ts — Replaced hardcoded Gemini Live model with config variable.
- app/api/ai/interview/route.ts — Adjusted import and function call to adapt to `systemInstruction`.
- app/api/ai/interview/[sessionId]/route.ts — Adapted backend to fetch full history via `formatHistoryForGemini` and inject it in `generateInterviewResponse()`.

Breaking changes:
- None

Notes for review:
- The JSON parsing robustness has been upgraded with a small RegEx cleaner. Keep an eye out just in case the AI outputs extremely malformed markdown json.
