[2026-03-28] — Fix Gemini Live Audio Playback Artifacts

What changed:
- Refactored `playAudioQueue` in `AudioControls.tsx` to use precise Web Audio API scheduling (`source.start(nextStartTime.current)`) instead of `await source.onended`.
- Added a `nextStartTime` ref to maintain gapless playback alignment for incoming PCM audio chunks.
- Scheduled a dynamic `setTimeout` to manage the `isPlaying` and UI indicators corresponding precisely to the hardware playback completion time.

Why:
- The previous implementation caused tiny silences between audio chunks because the JavaScript event loop is too slow to chain audio seamlessly. This resulted in audible clicks/pops between chunks.
- Gapless scheduling ensures the browser plays the incoming Gemini TTS voice stream as a single continuous soundwave, without artifacts.

Files affected:
- components/interview/AudioControls.tsx — Replaced `playAudioQueue` logic with latency-free context time scheduling.

Breaking changes:
- None
