2026-08-24 — Redesign B2B & Marketplace Sections into Interactive Tabs

What changed:
- Extracted the B2B (Espace École, Espace Recruteurs) and Marketplace (Job Board) promo banners from the `Features` component into a dedicated, interactive `B2BMarketplaceSection` component.
- Implemented a tabbed UI (Bento style) using `framer-motion` for smooth crossfades between the 3 sections.
- Unified the color theme to a sleek Slate/Blue for all three tabs (removing the distinct purple/indigo colors).
- Adjusted the layout of the active content to stack strictly vertically (`flex-col`) ensuring the text takes full width and never gets squished alongside the mockup on smaller desktop screens.

Why:
- The previous design stacked 3 massive banners vertically, consuming too much vertical space and appearing repetitive.
- The new tabbed interface offers a premium, modern SaaS feel (similar to Vercel/Stripe) and significantly improves user experience.
- Unifying the colors maintains a consistent brand identity without jarring color shifts.
- Layout adjustments ensure optimal typography readability across all screen sizes.

Files affected:
- components/landing/Features.tsx — Removed old stacked banners and imported the new section.
- components/landing/B2BMarketplaceSection.tsx — [NEW] Implemented the interactive tabbed section.
