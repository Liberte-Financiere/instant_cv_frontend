[2026-04-01] — Migrate audio Live API from Gemini 2.5 to 3.1 Flash Live Preview

What changed:
- Updated model string from gemini-2.5-flash-native-audio-preview-12-2025 to gemini-3.1-flash-live-preview
- Setup message: changed top-level key from "setup" to "config", flattened generationConfig (responseModalities and speechConfig are now direct children of config)
- Trigger message: replaced clientContent with realtimeInput.text
- Audio sending: replaced mediaChunks array with single audio object { data, mimeType }
- Text sending: replaced clientContent with realtimeInput.text for mid-conversation text input

Why:
- Gemini 3.1 Flash Live Preview is the new recommended model for real-time audio
- The WebSocket message format has changed (documented migration guide)
- clientContent is now reserved for initial history priming only, not for runtime text input

Files affected:
- lib/config.ts — model string update
- lib/interview-audio.ts — all 4 message format changes (setup, trigger, audio, text)

Breaking changes:
- None for end users. Backend-only changes.

Notes for review:
- Voice "Aoede" is kept in speechConfig — verify it still works with 3.1
- Transcriptions (inputTranscription/outputTranscription) are not handled yet; they are available in 3.1 server events but ignored for now
- The chunk/route.ts was NOT modified since it calls interview-audio.ts functions which were updated
