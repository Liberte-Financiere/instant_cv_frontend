[2026-08-17] — Design System: Migration vers les Design Tokens

What changed:
- Added semantic design tokens (success, warning, destructive, muted, border) to globals.css
- Refactored the school admin dashboard to use these new semantic tokens instead of hardcoded Tailwind colors.

Why:
- To eliminate hardcoded CSS colors and ensure the UI strictly respects the global design system. This sets a solid foundation for future theming (e.g., dark mode) and UI consistency.

Files affected:
- app/globals.css — Added semantic color tokens to :root and @theme.
- app/dashboard/school-admin/page.tsx — Refactored all statistics cards to use bg-primary-light, text-warning, border-border, etc.

Breaking changes:
- None

Notes for review:
- The design is now fully driven by tokens. Any future color adjustments should be made centrally in globals.css.
