2026-06-16 — Fix AI Logging TypeScript Errors & Token Metric Property Names

What changed:
- Updated Vercel AI SDK token property references to use `inputTokens` and `outputTokens` instead of `promptTokens` and `completionTokens` to match the latest SDK updates.
- Scoped `session` correctly in the `catch` blocks by declaring `let session: any;` above the `try` block in all AI feature endpoints (`match`, `translate`, `optimize`, `cover-letter/generate`, `cover-letter/refine`).
- Added `isSearchable: false` to all dummy and mock CV profiles (`lib/mock-cv.ts`, `lib/mock-cv-profiles.ts`, `TemplateDummyData.ts`, and initial state in `useCVStore.ts`) to align with the updated `CV` schema.
- Added `userId` to `RecruiterContext` in `lib/talent-assistant.ts` and passed the session user ID from the `app/api/recruiter/chat/route.ts` caller.
- Cleaned up duplicated `auth` imports.

Why:
- The implementation of the AI Logging infrastructure caused several TypeScript errors during `tsc --noEmit`, mainly due to the Vercel AI SDK updating the `LanguageModelUsage` property names, and the updated Prisma models imposing new typing requirements that were not reflected in the existing mock objects.
