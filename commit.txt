[2026-04-30] — Fix Gemini Live API WebSocket Payload

What changed:
- Changed the root key of the initial WebSocket payload from `config` to `setup`
- Grouped `responseModalities` and `speechConfig` under `generationConfig`

Why:
- The Gemini Multimodal Live API (`BidiGenerateContentSetup` schema) strictly requires the initial payload to use the `setup` key.
- Using `config` caused the Google server to reject the connection immediately with error code 1007: `Unknown name "config": Cannot find field.`
- The `responseModalities` and `speechConfig` fields are structurally nested under `generationConfig` according to the API specification.

Files affected:
- lib/interview-audio.ts — Updated the `setupMsg` payload structure.

Breaking changes:
- None

Notes for review:
- The `outputAudioTranscription` and `inputAudioTranscription` fields were kept at the root of `setup` as supported by recent Gemini Live API versions for native transcription features.
