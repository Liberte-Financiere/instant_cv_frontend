2026-05-30 — Refine Recruiter Portal UI and Sync Search Filters

What changed:
- Added a `lib/constants.ts` file to store a single source of truth for SECTORS.
- Refactored `SearchFilters.tsx` and `settings/page.tsx` to use the shared SECTORS constant.
- Updated `SearchFilters.tsx` to force text color to white (`!text-white`) for search inputs.
- Updated `SearchBar.tsx` to force text color to white (`!text-white`) for main search input.
- Added pagination (5 items per page) to the "Visibilité Recruteurs" CV list in `settings/page.tsx`.
- Refined UI/UX of the "Visibilité Recruteurs" section (replaced indigo colors with brand blue, added document icons, improved privacy banner).

Why:
- To fix a search bug where candidate profiles weren't found because sector keywords were mismatched between the frontend filter and the DB records.
- To prevent text from appearing black in dark mode for search inputs.
- To improve rendering performance and UX for candidates with dozens or hundreds of CVs.
- To maintain a professional, high-contrast, "Solid" design aesthetic aligned with the brand's blue primary color, entirely removing unwanted purple/indigo elements.

Files affected:
- lib/constants.ts — Created to hold the global `SECTORS` array.
- components/recruiter/SearchFilters.tsx — Applied `!text-white` to inputs, synced with `SECTORS` constant.
- components/recruiter/SearchBar.tsx — Applied `!text-white` to the input.
- app/dashboard/settings/page.tsx — Upgraded recruiter visibility UI, implemented pagination, synced sector select with `SECTORS` constant.

Breaking changes:
- None

Notes for review:
- The backend API (`/api/cv`) automatically orders CVs by `updatedAt: 'desc'`, so the pagination natively surfaces the most recent CVs on the first page.
- Recruiter search now matches profiles correctly based on the updated sector constants.
