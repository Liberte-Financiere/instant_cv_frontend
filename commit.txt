2026-06-06 — Professionnalisation de la Suite de Tests Unitaires et Rapport de Couverture

What changed:
- Configuration et mise en place d'un Mock Prisma global (`__tests__/setup/prisma-mock.ts`) interceptant dynamiquement les appels de base de données pour permettre l'exécution fluide de toutes les suites de tests unitaires sans base de données physique ni variable d'environnement DATABASE_URL.
- Création de 7 nouvelles suites de tests unitaires couvrant les modules métiers critiques de l'application (rate-limiting, système de parrainage/invitation, coûts et soldes de crédits recruteurs/candidats, cohérence de la configuration globale applicative, sanitisation robuste des données CV, schémas de validation Zod, et intégration des callbacks de paiement LigdiCash).
- Ajout de tests de censure des URLs de dépôts de projets candidats (GitHub/GitLab) dans la logique d'anonymisation de CV afin de préserver l'identité des utilisateurs non débloqués.
- Installation et configuration de `@vitest/coverage-v8` pour générer un rapport de couverture de code complet au format HTML (`/coverage/index.html`).
- Nettoyage rigoureux : Retrait du bypass de connexion de développement ("Connexion dev" credentials provider) sur la page `/login` et dans `auth.ts` après validation des tests dans le navigateur pour garantir une sécurité hermétique.

Why:
- Permettre d'identifier instantanément les régressions et de valider les règles métiers de calcul de solde, quotas et sécurité.
- Offrir une visibilité complète sur le taux de couverture des fichiers sources via un rapport visuel et interactif standardisé.
- Éliminer toute faille de sécurité ou backdoor de contournement d'authentification en environnement de développement avant passage en production.

Files affected:
- vitest.config.ts — Configuration de l'environnement de test avec `setupFiles` et configuration du reporter de couverture (HTML, json, text).
- __tests__/setup/prisma-mock.ts — Mock global de Prisma.
- __tests__/rate-limit.test.ts — Tests unitaires de la logique de rate limit.
- __tests__/referral.test.ts — Tests unitaires du calcul de crédits et génération de codes parrainage.
- __tests__/credits.test.ts — Tests unitaires de validation des coûts d'actions et erreurs crédits.
- __tests__/config.test.ts — Tests unitaires de conformité de la configuration globale.
- __tests__/utils.test.ts — Tests unitaires de la sanitisation des données de CV.
- __tests__/schemas.test.ts — Tests unitaires de validation de structures via Zod.
- __tests__/ligdicash.test.ts — Tests unitaires de la logique pure de paiement.
- __tests__/anonymize.test.ts — Ajout des scénarios de censure des URLs de projets Git.
- auth.ts — Suppression sécurisée du credentials provider de contournement de dev.
- app/login/page.tsx — Suppression du formulaire de bypass de développement.
