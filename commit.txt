[2026-08-22] — Feature: Dynamic Skill Categorization for CV Templates

What changed:
- Added a `category` field to the `Skill` interface to support dynamic categorization.
- Refactored `SkillsForm` in the CV editor to use a strict dropdown for categories (Compétences Techniques, Compétences Numériques, etc.), and implemented auto-selection for new items to speed up data entry.
- Created a centralized utility function `groupSkillsByCategory` in `lib/utils.ts` to logically group skills.
- Implemented category grouping in `CVSkills.tsx` and `ATSFriendlyTemplate.tsx`.
- Refactored 6 popular CV templates (ModernSidebar, Nordic, BoldHeader, TimelinePro, ClassicSerif, MinimalistTemplate) to use the new grouping helper and display contextual subheadings natively.
- Simplified the default section title for "Compétences" in the academic mode (in `constants/sections.ts`) since the categorisation is now dynamically handled inside the section itself.

Why:
- To allow students and professionals (such as UVBF students) to cleanly categorize their skills without introducing rigid structural changes to the database or state manager.
- Ensures cross-template compatibility and respects the DRY principle.

Files affected:
- frontend/instant_cv/types/cv.ts — Added optional category property to Skill type
- frontend/instant_cv/components/editor/forms/SkillsForm.tsx — Added category dropdown and sticky selection logic
- frontend/instant_cv/lib/utils.ts — Created `groupSkillsByCategory` and updated `sanitizeCVData`
- frontend/instant_cv/constants/sections.ts — Reverted academic title to generic "COMPÉTENCES"
- frontend/instant_cv/components/cv-sections/CVSkills.tsx — Added conditional grouping logic
- frontend/instant_cv/components/templates/*.tsx — Injected `groupSkillsByCategory` into ModernSidebar, Nordic, BoldHeader, TimelinePro, ClassicSerif, MinimalistTemplate, ATSFriendlyTemplate

Breaking changes:
- None. Templates not yet updated will simply display skills in a flat list as they did before.

Notes for review:
- The tests are passing and the build is completely green.
- There are about 14 remaining templates that have custom `skills.map` rendering which will be updated in a follow-up commit to also support grouped categorization.
