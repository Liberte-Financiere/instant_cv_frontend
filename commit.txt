What changed:
- Added explicit text-slate-900 color classes to custom Input, Textarea, and Select components.
- Added text-slate-900 to native textareas in CV forms (Experience, Projects, Divers).
- Added text-slate-900 and select styling overrides to Cover Letter editor forms and fields.
- Appended a global fallback style in globals.css to force slate-900 text on all inputs, textareas, and select components with appropriate placeholder styling.
- Implemented `sanitizeCVData` helper inside `lib/utils.ts` to cleanly normalize, merge, and safe-format raw AI parsed data.
- Integrated `sanitizeCVData` in client-side `useCVStore.ts` inside `createImportedCV` to sanitize imports prior to state update and persistence.
- Integrated `sanitizeCVData` as a server-side shield in `app/api/cv/route.ts` right before calling `cvSchema.safeParse`, ensuring 100% database-level safety against minor parsing anomalies (invalid email fields, unrecognized language levels, or malformed social URLs).
- Added `updateTemplateId` action in `store/useCVStore.ts` store.
- Built a premium `TemplateSelector` component at `components/editor/TemplateSelector.tsx` rendering all templates with real previews in a smooth modern modal.
- Integrated the new `TemplateSelector` into the main Editor toolbar (`app/editor/[id]/page.tsx`), enabling users to change their CV template/model dynamically in real-time.

Why:
- System dark mode settings on some devices (especially mobile Safari and Chrome) automatically styled typed text within inputs as white/light gray. Without an explicit text color configuration, white text on white/light backgrounds made typed content completely invisible.
- AI-parsed CV imports generated irregular field values (e.g. invalid emails, unrecognized language levels, platform strings outside enums, or non-schema URLs) which strictly failed database validation on the POST /api/cv endpoint, resulting in a 400 Bad Request and causing client creation failure.
- When users imported a CV via the AI Magic Analyzer, it defaulted to the "Le Moderne" style without offering a way to switch or choose a model, locking the imported CV to one layout forever. Adding a template selector inside the editor solves this restriction for both imported and regular CVs.
