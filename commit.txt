[2026-07-11] — Fix: Utilisation de la variable d'environnement pour l'URL du microservice Python

What changed:
- Remplacement de l'URL hardcodée (`http://127.0.0.1:3001/remove-bg`) par l'utilisation de `process.env.PYTHON_MICROSERVICE_URL` avec fallback sur `http://127.0.0.1:3001`.

Why:
- C'est une mauvaise pratique d'avoir des URLs en dur dans le code.
- Cela garantit que la configuration expliquée dans le README (où l'utilisateur définit `PYTHON_MICROSERVICE_URL=...` dans le fichier `.env`) sera bien respectée en production.

Files affected:
- app/api/ai/remove-bg/route.ts — Modification de l'appel `fetch` pour utiliser `process.env.PYTHON_MICROSERVICE_URL`.

Breaking changes:
- None.

Notes for review:
- Le fallback sur `http://127.0.0.1:3001` assure que ça fonctionne out-of-the-box en développement si la variable n'est pas encore définie dans `.env`.
