[2026-08-24] — Refactor: Secure document access MVP & PDF enforcement

What changed:
- Enforced PDF-only uploads on the candidate application form (`app/jobs/[id]/apply/page.tsx`) using both HTML `accept` attributes and client-side JS validation.
- Refactored the Document Viewer in the ATS (`app/recruiter/jobs/[id]/applications/page.tsx`). Removed the `iframe` implementation to comply with strict `X-Frame-Options: DENY` Nginx/Next.js security policies.

Why:
- Recruiters prefer PDFs to guarantee formatting consistency. Forcing PDF uploads reduces edge cases (like DOCX rendering issues).
- The strict security headers set globally on the server (Nginx/Next) block iframe embedding (`X-Frame-Options: DENY`). Opening the secure proxy link in a new tab bypasses this restriction legally while maintaining access control, keeping the MVP simple and robust.
